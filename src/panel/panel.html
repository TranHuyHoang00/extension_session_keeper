Cài đặt

      

        

        

        

        

        

        

          Nâng cao: đẩy token lên server (mặc định tắt)
          

            Khi bật, extension sẽ gửi giá trị token ra ngoài để máy/dự án khác lấy.
            Chỉ dùng với server bạn kiểm soát, luôn đặt khóa bí mật, và nên hỏi bộ phận bảo mật trước.
          

          
          
        


        

          
          
          
        

      

      

      

        Cài đặt được lưu theo website, nên lần sau gắn lại tab của website này sẽ dùng luôn.
        Extension không tự gọi API và không mở tab mới. Mặc định cũng không gửi token đi đâu;
        chỉ khi bạn bật "đẩy token lên server" ở trên thì token mới được gửi tới server đó.
